# Input data

All scripts read and write below one data root (environment variable `RESDOS_ROOT` or `config.json`).

## 1. Public MRTDosimetry images (OSF, doi:10.17605/OSF.IO/69NGE, CC BY 4.0)

Download from the OSF repository (Imaging datasets, https://osf.io/9qr8x/) and save under the names below.
All images: GE Discovery 670, reconstructed in GE Xeleris 3.11.08 (OSEM 4 iterations x 10 subsets, CT-based
attenuation correction, TEW scatter correction, resolution recovery ON, no post-filter) according to the dataset README.

| Save as | Dataset folder |
|---|---|
| `input/1h_SPECT_GE.dcm` ... `input/144h_SPECT_GE.dcm` (1h, 4h, 24h, 40h, 72h, 144h) | Four-organ Phantom → Reconstructed SPECT → RR ON → `001 h` ... `144 h` (one file per time point; rename as shown) |
| `input/GE_TEW_RR_4X10.dcm` | NEMA IEC phantom → Reconstructed SPECT → RR ON → `GE_TEW_RR_4X10.dcm`. The folder contains a dozen similarly named reconstructions (e.g. `..._40X2`, `..._45X2`); use exactly this file (4 iterations x 10 subsets). |
| `input/nema_ct/*.dcm` (161 slices) | NEMA IEC phantom → CT (OSF can download the whole folder as a zip; extract the 161 DICOM files) |

## 2. Derived data of the authors (Zenodo, [doi:10.5281/zenodo.24343110](https://doi.org/10.5281/zenodo.24343110); CC BY 4.0)

Extract the archive into the data root and check it with `python scripts/verify_checksums.py <extracted folder>` (expected: 61/61 OK).

| Path | Content |
|---|---|
| `input/truth_{1h,4h,24h,40h,72h,144h}_reg.dcm` | Noise-free ground-truth activity maps (128^3, 4.42 mm) built from the dataset CT, the OsiriX segmentation and the Table 1 concentrations (Methods 2.1). Pixel value x RescaleSlope = counts of a 1800-s acquisition with 11.94 cps/MBq, so that the maps can be processed like the measured SPECT; activity concentration [kBq/mL] = counts x 1000 / (11.94 x 1800 x 0.08633 mL) = counts x 0.539 (the code uses 0.5388) |
| `input/MRT_Segmentation.nrrd` | 3D Slicer segmentation of liver, tumour, spleen and kidneys on the dataset CT (VOIs) |
| `input/CTStd_2_5mmTomo_Day0.rois_series` | OsiriX MD ROI series used to build the ground-truth maps (original record, OsiriX format; read by step p05) |
| `input/osirix_masks/osirix_<structure>.nrrd` | The same contours as binary NRRD files (open format; geometry of `MRT_Segmentation.nrrd`), for use without OsiriX; written by `scripts/export_osirix_masks_nrrd.py` |
| `derived/opendose3d/fw00, fw05, fw075, fw10, fw125, fw15` | OpenDose3D Segment-statistics tables of the dose rates of the GT maps blurred to 0, 5, 7.5, 10, 12.5, 15 mm FWHM |
| `derived/opendose3d/fwspect` | OpenDose3D dose-rate tables of the measured SPECT (calibration 10.705 cps/MBq, 1800 s) |
| `derived/kernels/` | 177Lu soft-tissue voxel S-value kernel of PyTheranostics 0.1 (unmodified; Apache License 2.0, licence file included) |

The OpenDose3D tables are named as exported (hour labels assigned by OpenDose3D); the nominal times 1, 4, 24, 40, 72
and 144 h are used in file order.

## 3. Voxel S-value kernel (step p04)

`derived/kernels/DK_softtissueICRP_mGyperdecay.img` (51^3 voxels, 4.7952 mm; with its .hdr and licence) is included
in the derived-data record. It is the unmodified 177Lu soft-tissue kernel of PyTheranostics 0.1 (Apache License 2.0).
Version 0.1 is no longer listed on PyPI and later versions do not contain the kernel; if the file is missing, step
p04 tries to download the original 0.1 wheel from the PyPI file server. The SHA-256 is checked in every case:
533be3195abccfcdd4ebe8fe0bb8e969539c537f52df2b3e62233d89dbba1022

## 4. Generated by the scripts

`python run_all.py` creates `derived/seg.npy, segfrac.npy, seglab.npy, raw.npy, frac_tp_avg.npy, vsv_lu177_4.42mm.npy,
osirix_masks_+0.5.npz` (steps p01-p05, about 20 s) and everything in `results/`.
